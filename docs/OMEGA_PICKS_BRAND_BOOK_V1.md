# OMEGA PICKS — BRAND BOOK V1

## Estado
**IDENTIDAD VISUAL OFICIAL CONGELADA — 28-OCT-2026**

OMEGA PICKS es la marca pública. MATRIX continúa como nombre interno del motor analítico y de gobierno.

## Mensajes oficiales
- **Slogan principal:** Los datos hablan. Tú decides.
- **Campaña:** El deporte se siente. Las decisiones se calculan.
- **Técnico/comercial:** Analizamos datos. Buscamos valor.

## Símbolo
La identidad usa una **Ω** combinada con una **gráfica estadística ascendente**. La gráfica representa análisis y evolución; no representa rentabilidad garantizada.

## Reglas
1. El logo principal se usa sobre grafito o fondos de alto contraste.
2. El avatar usa únicamente Ω + gráfica; no lleva slogan.
3. Debe existir siempre versión monocromática.
4. No usar fichas de casino, ruletas, cartas, trofeos genéricos ni símbolos de “ganancia segura”.
5. No cambiar los slogans aprobados sin revisión de Brand Strategy + Compliance.
6. Ninguna pieza puede usar “seguro”, “garantizado”, “100%” o equivalentes para resultados.
7. La marca debe mantener lectura clara en móvil.

## Colorimetría
El sistema prioriza azul eléctrico + grafito + plata + blanco porque el posicionamiento es sports-tech y analítico. Cian refuerza dinamismo digital. Los colores funcionales se mantienen separados para que un estado de apuesta no altere la identidad de marca.
